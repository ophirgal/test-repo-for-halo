Choices made in this screen set

  • Error messages appear under the field and are linked to it with aria-describedby and aria-invalid. Each message has an icon and bold text in #b3261e (6.5:1 on white), so colour is never the only signal. The field gets a 2 px red border. When several fields are wrong, each one shows its own message and focus goes to the first.
  • Focus moves to the first field in error. The pages show this with autofocus; the build sets it on submit. Focus order on every screen is Back, then the fields, then the main button. The focus ring is a 3 px dark blue outline (#1f3cae).
  • Submit is a link on the review pages so they can be clicked through without scripts. The build uses a real <button type="submit">, as the submitting state shows.
  • Name is capped at 80 characters (maxlength), as the structure recommends, so there is no "too long" error.
  • Submitting shows the spinner inside the button, where the result will appear. No skeleton is needed, because the next page is the Confirmation.
  • The dashed review bar at the top of each page links back to this gallery. It is for review only and is not part of the product.
