Each screen is shown as a desktop browser at 1280×800: you asked for desktop screens only, so there is no mobile layout.

Choices made in this prototype
  • Desktop only, as you asked: every page is laid out for a desktop browser and the phone layout is gone (the thumbnails show 1280×800). This sets aside the mobile part of R4 and acceptance criterion 1, which ask for desktop and mobile widths; the screens step will draw desktop pages only.
  • Matcha theme: every colour is a shade of matcha green (page #eef4e2, buttons and links #4a6b25, focus ring #2d4214); every pairing meets WCAG 2.1 AA. Layout, type and spacing come from the approved newsletter design.
  • A decorative matcha illustration (inline SVG, hidden from screen readers) tops Welcome, Signup form and Confirmation.
  • On the site page, only the new footer takes the matcha theme, and the page’s content is centred; restyling the rest of the site is outside this story.
  • The Name field is capped at 80 characters (maxlength); there is no “name too long” error.
  • A three-step progress bar (Welcome, Your details, Done) shows the visitor’s current step.
  • The confirmation does not mention a confirmation email: this epic has no double opt-in. New and already-subscribed addresses see the same page.
  • Each screen also has a “← Back” link to the previous one. The error, submitting and submission-failed states of the form are drawn in the next step.
