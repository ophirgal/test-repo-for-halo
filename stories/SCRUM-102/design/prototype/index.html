Newsletter signup journey — prototype

This prototype covers the main path of SCRUM-102. A visitor follows the newsletter link in the site footer, reads the one-sentence welcome, enters a name and email address, and sees the confirmation. The visitor's details are filled in on every page (Maya Levi, maya.levi@example.com). Each page has a way back. Narrow the viewer to under 480 px to see the mobile layout. The error, submitting and submission-failed states of the form are drawn in the next step.

Screens

  1. Site page — footer link. This is today's page from docs/index.html, unchanged except for a new footer with a "Newsletter" link. The page has no footer today.
  2. Welcome (new): a one-sentence description of the newsletter and a "Subscribe" button.
  3. Signup form (new): the Name and Email address fields, with a "Submit" button.
  4. Confirmation (new): "You're subscribed". New and already-subscribed addresses see the same page.

Choices made in this prototype

  • The new screens reuse the visual base of the approved newsletter design in story 0e4e726a, as recommended in the structure. One change: the focus ring is dark blue instead of yellow so that it meets the AA contrast requirement. Input borders are also darker, for the same reason.
  • The Name field is capped at 80 characters (maxlength), as recommended in the structure. There is no "name too long" error.
  • A three-step progress bar (Welcome, Your details, Done) shows the visitor's current step.
  • The confirmation does not mention a confirmation email, because this epic has no double opt-in.
  • The design viewer runs no scripts, so "Submit" is a link straight to the confirmation.
