Each screen is shown as a desktop browser at 1280×800: you asked for desktop screens only, so there is no mobile layout.

Choices made in this prototype
  • Purple neon 80s sports-car theme, replacing matcha as you asked: a night-purple page (#120624) with a violet glow, a dark violet card (#1f0d3a) edged in neon pink, neon pink uppercase buttons (#ff4fd8) with dark text, violet links (#e0a6ff), a glowing italic heading and a cyan focus ring (#39f3ff). Every pairing meets WCAG 2.1 AA: body text 15.8:1, button text 6.6:1, links 9.4:1, focus ring 13:1, input borders 5.4:1.
  • A decorative sports-car illustration replaces the matcha one at the top of Welcome, Signup form and Confirmation: a generic wedge-shaped coupe (not a real model) on a neon grid road under a striped sunset, with violet mountains. It is inline SVG and hidden from screen readers, so focus order is unchanged.
  • Desktop only, as you asked earlier: every page is laid out for a desktop browser (the thumbnails show 1280×800). This sets aside the mobile part of R4 and acceptance criterion 1; the screens step will draw desktop pages only.
  • On the site page, only the new footer takes the neon theme (a night-purple bar with a pink neon edge); the page’s content is centred and otherwise as it is today, because restyling the rest of the site is outside this story.
  • The Name field is capped at 80 characters (maxlength); there is no “name too long” error.
  • A three-step progress bar (Welcome, Your details, Done) shows the visitor’s current step, lit in neon pink.
  • The confirmation does not mention a confirmation email: this epic has no double opt-in. New and already-subscribed addresses see the same page.
  • Each screen also has a “← Back” link to the previous one. The error, submitting and submission-failed states of the form are drawn in the next step.
