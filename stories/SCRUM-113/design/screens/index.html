Choices made in this screen set

  • States: only the states the structure's inventory names. Welcome has default and loading, Game — playing has default and empty, and Game — paused and Game over each have default. The game makes no network calls, so no screen has an error state.
  • Desktop layout: the same single centred column as the phone. The board grows to fit the window (at most 600 px), and the title and art get bigger. Overlays still cover the board.
  • Desktop steering: the hint reads “Swipe or use the arrow keys to steer”, because a desktop browser has no swipe. The phone keeps “Swipe anywhere to steer” (open branch 1: swipe only, no arrow pad).
  • Start of a round (empty): a one-time “Swipe to start moving” hint above the board. The snake stays still until the first swipe, so a round doesn't start before the gamer is ready.
  • Loading: a progress bar under the art and a disabled “Loading” button with a spinner. It appears on first open only, because the game then runs offline.
  • Flow: Play and Play again open the start of a round (empty). Resume returns to the round in progress. Quit and Home go back to Welcome.
  • Prototype-only links (no script): tap the board to move the round forward (empty → playing → game over), and use the skip link on loading. The built game doesn't have these.
  • No best score (open branch 2). Speed rises with the score (open branch 4) and can't be seen in a still page. The food pulse, tongue flick and spinner stop under reduced motion.
  • “Road Snake” is a sample game name, as in the prototype.
