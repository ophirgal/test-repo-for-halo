Choices made in this screen set
  • States: only those the structure names. Welcome and Game over have one state; Game has playing and paused. None of the screens loads data, so there are no loading, empty or error states.
  • Desktop pages: the structure targets phones in portrait. Desktop shows the same single column centred, up to 600 px wide, with larger type and buttons. Steering is still swipe; desktop controls such as arrow keys were not asked for.
  • From the prototype, unchanged: dark palette, cyan-to-lime glowing snake with eyes and tongue, pink berry, score and Pause floating above the field, centred actions.
  • Removed from the prototype: the hint “tap the field to see the snake crash”. To walk the flow, tapping the field still links to Game over.
  • Paused: marked as a dialog for screen readers; the game behind is hidden from them.
  • The berry pulses gently and stops when the phone asks for reduced motion.
