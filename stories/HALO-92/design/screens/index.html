Screen set

This is the full design of the one new screen in the approved structure: the static page at /jungle. It keeps the look approved in the prototype. A large yellow "Hello World!" sits on deep green, framed by leaf clusters, side vines and bushes on an earth-brown ground. It is shown in its only state, as a desktop and a mobile pair. Choices noted for review

  • Only the default state is drawn. The inventory marks loading, error and empty as n/a. The page is static and self-contained, so nothing loads late. A wrong address goes to the existing "Not found", and the content is fixed.
  • The inventory lists desktop and mobile 375 as two entries of one screen. They are drawn here as the desktop and mobile pair of jungle-page.
  • Not drawn: the existing greeting page at / and "Not found". The structure marks both as unchanged and out of scope.
  • The open-branch defaults from the structure are kept, as in the approved prototype. Desktop is 1440 px, with no tablet layout. The heading is yellow on deep green, in the system bold font. At 375 px the heading wraps to two lines, the leaves and bushes shrink, and the vines are hidden.
  • Each page has a review bar on top (back to this gallery, and a desktop/mobile switch) and spec notes below. Neither is part of the jungle page, which itself has no links or buttons.
