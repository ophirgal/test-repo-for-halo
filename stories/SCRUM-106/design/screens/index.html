Corner Bean — home screen: all states

The complete screen set for SCRUM-106, a clone of SCRUM-105: the cafe app's Home screen in its four states (default, loading, error, empty), each as a desktop and a mobile page. Layout, navigation, tokens and sample content follow the approved prototype, which carries the approved SCRUM-105 Home over unchanged.

Home · based on SCRUM-105 Home

Rendering choices

  • Desktop layout: the bottom tab bar becomes a top bar with the same four entries (Home · Menu · Visit · More); hours/location card and View full menu sit in a left column, favourites in a four-across grid on the right. Pull to refresh becomes a Refresh link.
  • Loading: the hours/location card is skeletoned too, not only the favourites — both come from the same content load, so both are pending.
  • Error: the whole content area is replaced (hours, location and favourites all failed together); header and navigation stay usable. “Try again” leads to Loading.
  • Empty: only the favourites are missing; hours, location and the menu entry stay.
  • Leaving Home: menu, directions, items and other tabs open an “out of scope” note with a way back, as in the prototype.
  • Each page has a review bar above the screen (gallery link, state switcher, desktop/mobile switch); it is review chrome, not part of the design.
