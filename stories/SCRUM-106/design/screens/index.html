Corner Bean — home screen: all states

The complete screen set for SCRUM-106, a clone of SCRUM-105: the cafe app's Home screen in its four states (default, loading, error, empty), each as a desktop and a mobile page. Layout, navigation and sample content follow the approved prototype, which carries the approved SCRUM-105 Home over unchanged. This version applies the designer's change request: the background is now black, on every page and in every state.

Home · based on SCRUM-105 Home

What changed from SCRUM-105: the screen background is black instead of cream, with the text that sits directly on it (cafe name, tagline, section titles, pull-to-refresh and “Updating…” hints) switched to light tones; layout, content and states are otherwise the approved SCRUM-105 screens, and the “out of scope” note now reads SCRUM-106.

Rendering choices

  • Black background: --c-bg in the shared tokens.css is now pure black (#000), so the change applies to all eight pages at once. Only the background changed: the white cards, favourite tiles, top bar and tab bar keep their colours and dark text, and the brown brand button is unchanged. Text placed straight on black uses two new light tokens (cream #f5efe8, muted #b5a99e) and links use a lighter caramel (#e0b48c) so they stay readable. If you'd like the cards and bars to go dark as well (a full dark theme), say so and I'll restyle them.
  • Desktop layout: the bottom tab bar becomes a top bar with the same four entries (Home · Menu · Visit · More); hours/location card and View full menu sit in a left column, favourites in a four-across grid on the right. Pull to refresh becomes a Refresh link.
  • Loading: the hours/location card is skeletoned too, not only the favourites — both come from the same content load, so both are pending.
  • Error: the whole content area is replaced (hours, location and favourites all failed together); header and navigation stay usable. “Try again” leads to Loading.
  • Empty: only the favourites are missing; hours, location and the menu entry stay.
  • Leaving Home: menu, directions, items and other tabs open an “out of scope” note with a way back, as in the prototype.
  • Each page has a review bar above the screen (gallery link, state switcher, desktop/mobile switch); it is review chrome, not part of the design.
