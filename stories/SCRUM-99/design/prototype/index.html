Newsletter signup journey — prototype

This clickable prototype walks the main path of SCRUM-99: from the new footer link on any site page to the Welcome screen, the Signup form and the Confirmation, then back to the site. It keeps the site's current look (system font, plain page with 1rem padding, from docs/index.html) and adds only a small, AA-contrast palette for the button, fields and footer. Every page fits a phone width; resize the viewer to check mobile.

Screens

  1. Any site page — rebuilt from docs/index.html; the only change from today is a new site footer with a Newsletter link (the site has no footer today).
  2. Welcome — new: one sentence about the newsletter and a Subscribe button.
  3. Signup form — new: Name and Email address, filled in with a valid sample, Submit and Back.
  4. Confirmation — new: "You're subscribed" with the address, and Back to the site.

Choices made in this prototype

  • The three screens are separate pages, not a dialog (structure, open branch 5).
  • "Back to the site" goes to the home page (open branch 6).
  • The Name field stops input at 80 characters, shown as a hint under the label (open branch 3).
  • The viewer runs no scripts, so Submit is a link straight to the Confirmation. The inline errors (empty name, empty email, malformed email), the submitting state and the submission-failed state are drawn in the next step.
