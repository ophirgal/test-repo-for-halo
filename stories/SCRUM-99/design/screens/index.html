Choices made in this screen set

  • Each inline-error page shows one error with the other field valid, as the structure draws them; when several fields fail at once, each shows its own message together (open branch 2).
  • Errors are text plus an icon, never colour alone; the field gets a thicker red border, aria-invalid and aria-describedby, the page title starts with "Error:", and focus moves to the first field in error (shown with the focus ring).
  • Focus order on every screen follows reading order: Back, then Name, Email address, Submit, then the footer links.
  • Submitting keeps the fields visible but read-only and turns Submit into a disabled "Subscribing…" button with a spinner (slowed for reduced motion). The viewer runs no scripts, so its two outcomes are links in the note under the page.
  • Submission failed shows its message above the form with role="alert", keeps the typed values, and Submit is the retry (open branch 4).
  • The Name field stops input at 80 characters, so there is no separate "too long" state (open branch 3).
