Neon Nights Weekly · signup prototype

This is a clickable prototype of the main path through the single Neon Nights Weekly signup page, laid out as in the approved structure. A music fan lands on the neon page, types an address, ticks the consent box and presses Subscribe. The page shows the send in progress, then swaps the form for a “check your inbox” confirmation, all without leaving the page (R1). The reduced-motion variant of the first screen is included as well. Each page is responsive: narrow the window to 320 px to see the phone layout, where the illustration shrinks and moves below the form. A grey dashed bar marks prototype controls; it is not part of the design.

Screens on the main path

  1. Signup — default: the neon sign (slow flicker), the blurb, the email field, the unticked consent box with a privacy link, and Subscribe. Step 1–2.
  2. Signup — default, reduced motion: the same screen with a fully static sign (AC 4).
  3. Signup — submitting: progress shown and a second press blocked (R6). From here you choose “new address” or “already subscribed”; both go to the same confirmation (R9). Step 4.
  4. Signup — confirmation: replaces the form, shows fan@example.com and asks the visitor to check their inbox (R7). Step 5.

Not in this step (drawn next, in Screens): invalid email, consent missing, both errors and send failed, each at 320 px and desktop.

Interaction choices made for the prototype

  • Validation on submit only. The structure’s proposed default (open branch 1); the error screens come next.
  • Privacy link opens an in-page placeholder note. In the built page it opens in a new tab and points to the approved address before go-live (open branch 3).
  • Tab order is email → consent → Subscribe. Use “Show Tab order” in the grey bar to see the numbers (AC 6). The focus ring is turquoise, 3 px, offset.
  • Confirmation is final. No “change address” link (open branch 4); focus moves to the message (open branch 2).
  • No sound, no site navigation on any screen (R1, R15).

Fonts and illustration (for approval)

  • Fonts: system fonts only (Futura / Century Gothic / Trebuchet for the sign, the device’s UI font for the body). Nothing is downloaded, so there is no licence to clear (AC 5).
  • Illustration A, a big-hair figure in an oversized shoulder-pad jacket. Source: drawn for this prototype as inline vector art. Licence: original work. It depicts no artist, album cover or lyric. Status: proposed, pending the product owner’s approval. If it is rejected it is removed, and the page stays whole with neon only (R11).
