Choices made in this set

  • Only the default state is drawn for each screen. The inventory marks loading, error and empty as n/a: the page is static, and it is itself the error.
  • The desktop page keeps concept A as approved: a 36rem centred column at the top of the window, a small letter-spaced “404” (hidden from screen readers), the h1 at the browser’s default size, and an underlined text link.
  • The phone page has the same content in one column, a 1.75rem heading so “Page not found” stays on one line at 320 px, and a link at least 48 px tall.
  • Colours are today’s browser defaults: black text on white (21:1), blue link #0000ee (9.4:1), grey mark #595959 (7:1). The link has a 3 px black focus outline.
  • In this set the link goes to the Home page of the same width. In the build it points to /. The broken URL is never shown on the page.
