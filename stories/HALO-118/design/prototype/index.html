Minimal Snake — clickable prototype

This prototype walks the main path of the approved structure for HALO-118. There is one page, the Game page, and the player passes through three of its states: Ready → Playing → Game over → Ready. The player uses only the keyboard. Each key press is simulated by a link in the yellow "Prototype controls" panel next to the game. That panel is not part of the game. The game itself has only a score line, a square 20 × 20 field and a message line. The Error state is not on the main path, so it is left for the screens step.

Screens

  • Game page, with three states:
    • Ready: page just opened, snake still, score 0
    • Playing: snake moving, score 3
    • Game over: snake hit the wall, final score 5

Choices taken from the structure's defaults

  • After Game over, any key starts a new round in Ready. The next arrow or WASD key starts the movement.
  • The Game over message sits in the message line below the field. The frozen snake stays visible on the field.
  • While the snake is moving, the message line is empty, so only the score line, field, snake and food are shown (AC 2).
  • Palette: a white field with light grid lines, a green snake with a darker head, one red food cell and dark text. The page has no images, buttons or decoration (AC 2, AC 3).
