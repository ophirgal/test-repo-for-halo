Minimal Snake: screen set (HALO-118)

The game has one screen, the Game page, shown here in the four states from the approved structure: Ready, Playing, Game over and Error (AC 1). Each state has a desktop page and a mobile page. The grey bar at the top of each page is review chrome for moving around the gallery; it is not part of the game. The layout follows the approved prototype: a score line, a square 20 × 20 field and a message line under the field.

The structure marks Loading and Empty as n/a: the page starts at once, and a round always has a snake and one food item. Neither state has a page.

Design system (tokens.css)

  • Field #ffffff, with grid lines #ececE7 and a 1 px border #1d1d1b
  • Snake #2f6b3a head #1c4424
  • Food #c0392b, also used for the error panel border
  • Page #f4f4f1 · text #1d1d1b · system font, 16 px body, 20 px semibold score
  • Field: 20 × 20 cells, 400 px on desktop (20 px cells) and 320 px on mobile (16 px cells). Spacing steps: 4 / 8 / 16 / 24 / 40 px.

Choices noted for the build (HALO-119)

  • The mobile pages show only the layout at phone width. Touch controls stay out of scope (D-2), so the hints still name the keyboard.
  • The Error state uses the default from the structure: a generic cause with no technical diagnosis, and the way out is to use a current browser.
  • The page has no title, buttons, icons or images. The game's only interactive input is the keyboard (AC 2, AC 3).
